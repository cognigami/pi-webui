# Local UI fonts

Unmodified Google Sans regular/italic variable fonts, copied from the operator's
local Dreamcoat font bundle. Upstream: https://github.com/google/fonts/tree/main/ofl/googlesans

Copyright 2025 The Google Sans Project Authors. Both files remain under the SIL
Open Font License 1.1 in `GoogleSans-OFL.txt`, also served at
`/fonts/GoogleSans-OFL.txt` by the embedded application. No system installation,
CDN, proprietary artwork or official branding is included.

CSS registers normal/italic 400–700 with `font-display: swap`; literal code uses
the system monospace stack. Actual browser font loading must be checked before
claiming a rendered screen used Google Sans.
